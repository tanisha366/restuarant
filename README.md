# Restaurant Website

This is a restaurant website where customers can view bar specials, reserve tables, and check the menu easily.

## Features

- 🍹 **Bar Specials**  
  Highlights daily drink specials and offers for customers.

- 📅 **Reserve Table**  
  Allows customers to book a table online by entering their name, date, and time.

- 📋 **Menu List**  
  Displays the full list of food and beverages available at the restaurant.

- 📱 **Responsive Design**  
  Works smoothly on mobile, tablet, and desktop devices.

## How to Use

1. Open the website.
2. Check the bar specials section to explore available offers.
3. Go to the "Reserve Table" section and fill out the form to book your table.
4. Browse the menu section for food and drink options.

## Technologies Used

- HTML
- CSS
- JavaScript ( for interactive features)
